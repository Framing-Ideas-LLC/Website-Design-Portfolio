# YNA Photobooths

A modern and responsive photography and photobooth landing page designed to showcase event services, rental packages, portfolio, and booking information. The website uses a clean dark-themed layout with high-quality visuals to create a premium user experience.

## Features

- Responsive landing page design
- Hero banner with call-to-action
- Photo Booth experience showcase
- DSLR Photobooth rental section
- About company section
- Service and package cards
- Booking call-to-action banner
- Equipment rental pricing
- Portfolio gallery
- Contact form
- Newsletter subscription
- Modern dark UI design

## Sections

- Header & Navigation
- Hero Section
- Photo Booth Experience
- DSLR Photobooth
- About YNA Photobooths
- Packages
- Booking Banner
- Equipment Pricing
- Work Portfolio
- Contact Section
- Footer

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Design Highlights

- Dark modern interface
- Professional photography-focused layout
- Card-based content presentation
- Large image gallery
- Clean typography
- Simple navigation
- Mobile-friendly design


## Purpose

This project is built to promote photography and photobooth services by presenting packages, rental options, portfolio, and contact information in a visually appealing and easy-to-navigate format.
