# Sugarcito Delights

## Project Overview

Sugarcito Delights is a modern dessert website designed to showcase delicious desserts, refreshing drinks, and sweet treats. The website features a premium visual style with soft pink tones, cream backgrounds, bold typography, and high-quality dessert photography.

## Key Features

- Responsive homepage design
- Announcement bar and navigation menu
- Hero section with promotional content and CTA buttons
- Featured dessert cards with category filters
- Product favourites section
- Brand introduction and story section
- Brand highlights and features
- Dessert image gallery
- Promotional banner with contact and social media links
- Footer with navigation and contact information
- Smooth scrolling and hover effects

## Design Style

- Premium and modern layout
- Soft pink, cream, and burgundy color palette
- Bold headings with elegant italic typography
- High-quality food photography
- Clean spacing and rounded image containers
- Consistent styling across all sections

## Color Palette

- Burgundy: #790024
- Pink: #F45186
- Soft Pink: #F8C5C7
- Cream: #FFF7ED
- Dark Text: #650020
- White: #FFFFFF

## Project Deliverables

- Complete homepage implementation
- Responsive layouts for desktop, tablet, and mobile
- Reusable website sections and components
- Optimized images and organized assets
- Functional navigation and CTA links
- Interactive product cards and category filters
- Clean and maintainable source code
- GitHub README and project documentation
- Final testing across screen sizes
