# HomeSafe

A modern responsive landing page designed for HomeSafe, an AI-powered lone worker safety and monitoring platform.

The website focuses on clear communication, trust, and safety through a clean enterprise-style interface. It presents HomeSafe’s automated monitoring capabilities, real-time visibility, safety features, use cases, ROI, customer testimonials, and industry applications.

## Key Features

* AI-powered lone worker monitoring
* Automated safety and incident detection
* Real-time location and activity visibility
* Safety workflow and monitoring process
* Industry-specific use cases
* Product and dashboard showcases
* ROI and business benefits section
* Customer testimonials
* Latest insights and resources
* Strong conversion-focused CTA sections
* Fully responsive layout

## Design

The design uses a clean, professional visual system with light backgrounds, dark navy sections, blue accents, rounded cards, subtle shadows, and product-focused imagery. The overall layout is structured to create a trustworthy and enterprise-ready experience for safety-focused businesses.
