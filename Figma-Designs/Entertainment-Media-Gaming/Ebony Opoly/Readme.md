## Ebony Opoly – Educational Board Game Website (Figma UI/UX)

**Ebony Opoly** is a modern educational board game website concept designed in **Figma** to celebrate Black excellence, legacy building, financial education, and wealth creation through an engaging gaming experience. The design focuses on combining entertainment, strategy, and real-world learning to create an experience that inspires players of different generations to think strategically, learn about wealth, and build a stronger understanding of financial success.

The website is crafted to highlight the game, gameplay experience, educational benefits, cultural inspiration, product details, player resources, and purchasing options while delivering a seamless experience across all devices. Bold visuals, vibrant layouts, engaging typography, and intuitive navigation create an exciting journey that reflects the game's focus on strategy, empowerment, and legacy.
