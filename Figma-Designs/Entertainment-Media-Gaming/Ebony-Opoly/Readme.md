## GitHub Project Description

**EbonyOpoly – Cultural Board Game E-Commerce Website**

EbonyOpoly is a modern e-commerce website designed for a board game brand that celebrates Black culture, history, and community through interactive gameplay. The website combines storytelling, product discovery, educational content, and community engagement in a clean and engaging shopping experience.

### Key Features

* Responsive and modern website layout
* Strong product-focused hero section
* Board game and brand introduction
* Product collection and merchandise showcase
* Educational and cultural storytelling sections
* Community-focused content
* Media and major network feature section
* Newsletter subscription
* Blog and educational content section
* Clear navigation and call-to-action buttons
* Structured footer with useful links and contact information
* Mobile-friendly design

### Design Approach

The design uses a warm, culture-focused visual style with neutral backgrounds, earthy brown accents, bold typography, and strong product photography. Custom section shapes and carefully structured content help give the website a distinctive brand identity while keeping the shopping experience simple and easy to navigate.

### Project Goal

The goal of this project was to create an engaging online presence for EbonyOpoly that not only showcases and sells its board games and merchandise but also communicates the brand's mission of celebrating Black excellence, preserving history, educating players, and bringing communities together.
