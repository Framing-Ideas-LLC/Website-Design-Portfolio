# DJ Infame

A modern event entertainment website designed for DJ Infame, focused on music, live entertainment, and unforgettable event experiences.

## Features

* Bold dark-themed visual design with gold accent colors
* Hero section with event-focused imagery and clear call-to-action
* DJ and event statistics section
* Services overview including custom soundtracks, audio engineering, live entertainment, and party hosting
* Event category navigation for DJ, business, music, party, and club events
* Featured event and experience sections
* DJ story and background section
* Image gallery showcasing events, performances, and behind-the-scenes moments
* Contact section with inquiry form
* Responsive layout for desktop and mobile devices
* Strong typography and high-impact imagery throughout the website

## Design

The website uses a dark black background combined with warm gold accents to create a premium nightlife and entertainment aesthetic. Large event photography, clean typography, spacious layouts, and subtle visual effects give the site an energetic yet professional feel.

## Purpose

The website is designed to showcase DJ Infame's services, experience, past events, and music-focused work while encouraging visitors to explore the services and book an event.
