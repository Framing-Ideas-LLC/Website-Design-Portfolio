# Aurevia Aesthetics

A modern and elegant aesthetic clinic website designed for Aurevia Aesthetics. The website focuses on showcasing aesthetic treatments, building trust through real results and testimonials, and encouraging visitors to book consultations.

## Features

* Clean and premium visual design
* Responsive layout for desktop and mobile
* Hero section with clear booking CTA
* Treatment services grid
* Before and after results section
* Treatment pricing and consultation section
* Why Choose Aurevia section
* Microneedling information section
* Client testimonials
* Appointment booking CTA
* Contact and location information
* Contact form
* Minimal and elegant typography
* Soft neutral color palette
