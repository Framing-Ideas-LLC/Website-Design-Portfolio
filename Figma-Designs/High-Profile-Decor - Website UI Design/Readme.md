# High Profile Decor Website

A premium interior design and home decor website created for High Profile Decor. The website features an elegant dark aesthetic with gold accents, refined typography, and a luxury-focused user experience.

## Overview

The website showcases luxury interior decorating services, exclusive home decor products, and personalized design consultations.

## Key Sections

- **Hero Section:** Full-screen interior background with brand messaging and consultation CTAs.
- **Services:** Residential decorating, commercial decorating, color consultation, home staging, room makeovers, and vacation rental styling.
- **About Section:** Brand story, design philosophy, and company introduction.
- **Shop Collection:** Exclusive decor products with product images and pricing.
- **Booking Section:** Consultation form with contact information and service selection.
- **Footer:** Brand identity, navigation links, and copyright information.

## Design Features

- Premium dark-themed design.
- Elegant gold accent colors.
- Sophisticated typography.
- Luxury interior photography.
- Clean and structured layouts.
- Clear call-to-action buttons.
- Product showcase with pricing.
- Consultation-focused user experience.
