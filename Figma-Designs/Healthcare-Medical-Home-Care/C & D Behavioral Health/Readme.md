# C&D Behavioral Health – Healthcare Website UI Design

A modern and professional healthcare website UI designed for a behavioral health and wellness center. The design focuses on trust, compassion, and accessibility while providing a clean user experience for patients seeking mental health and recovery services.

## Overview

This project features a calming visual style with soft neutral colors, elegant typography, and a well-structured layout. The interface highlights healthcare services, recovery programs, therapist information, patient success metrics, testimonials, and contact options to create a welcoming experience.

## Pages & Sections

* Hero Banner
* Featured Treatment Services
* About & Mission Section
* Recovery Statistics
* Care Benefits
* Featured Programs
* Recent Projects
* Contact Form
* Patient Testimonials
* Footer with Quick Links

## Design Features

* Clean and minimal healthcare-focused interface
* Soft color palette for a calming user experience
* Fully responsive layout
* Clear content hierarchy
* Professional service cards
* Call-to-action sections
* Testimonial slider
* Contact form with appointment inquiry
* Modern typography and balanced spacing

## Purpose

The goal of this project is to create a trustworthy and user-friendly healthcare website that helps patients easily explore services, learn about treatment programs, and connect with healthcare professionals through an intuitive and modern interface.
