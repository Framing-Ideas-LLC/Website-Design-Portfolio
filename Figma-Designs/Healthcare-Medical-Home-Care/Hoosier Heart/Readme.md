# Hoosier Heart – Home Care Website

A modern and compassionate healthcare website designed for a senior home care service provider. The design focuses on trust, accessibility, and clear communication while making it easy for families to explore services, book appointments, and learn about available care options.

## Project Overview

This website was created to present home care services in a professional and welcoming way. It combines warm colors, high-quality caregiving imagery, and structured content to build confidence and encourage visitors to take action.

## Design Highlights

* Clean and professional healthcare-focused layout
* Warm beige, white, and red color palette for a friendly appearance
* Strong hero section with clear call-to-action buttons
* Easy-to-read typography with balanced spacing
* Service cards for quick navigation
* High-quality caregiver and senior lifestyle imagery
* Responsive design optimized for desktop, tablet, and mobile devices

## Design Style

The interface follows a clean healthcare design with soft backgrounds, modern typography, rounded cards, subtle shadows, and carefully placed CTAs. The visual hierarchy helps visitors quickly understand the services while maintaining a warm and trustworthy user experience.

## Goal

The primary goal of the website is to help families easily discover senior care services, build trust through professional presentation, and increase appointment bookings through clear navigation and strategic call-to-action placement.
