# PulseCheck – Prison Communication Suite

PulseCheck is a modern prison communication platform designed to help incarcerated individuals stay connected with their loved ones. The website presents a range of communication services in a clean and professional interface.

## Features

* Communication services for photos, letters, postcards, and greeting cards
* Clear service navigation with dropdown menu support
* Mission statement section to explain the platform's purpose
* Step-by-step "How It Works" section
* Brand ambassador recruitment section
* CEO message section
* Customer testimonials
* Newsletter subscription form
* Detailed footer with important links and company information
* Fully responsive and modern website layout

## Design

The website uses a clean, minimal layout with a dark and light color combination. Teal is used as the primary accent color to highlight buttons, icons, cards, and important sections. Large imagery, structured content blocks, and card-based layouts create a professional and user-friendly experience.
