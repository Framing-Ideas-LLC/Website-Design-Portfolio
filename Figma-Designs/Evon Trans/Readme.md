# Evon Tran Nail Art Website

A luxury nail salon website designed for Evon Tran, focused on showcasing nail art, beauty services, and appointment bookings.

## Features

* Luxury and elegant visual design
* Hero section with appointment and gallery CTAs
* Nail art gallery with hover interactions
* Luxury services section with service cards
* About section introducing the nail artist
* Client testimonials
* Instagram-style beauty gallery
* Appointment booking form
* Responsive layout for different screen sizes
* Clean typography with a soft beauty-focused color palette

## Sections

* Hero
* Nail Art Gallery
* Luxury Services
* About
* Testimonials
* Social Gallery
* Appointment
* Footer

## Design

The website uses a soft blush and white color palette with elegant typography, rounded cards, high-quality nail photography, and a minimal luxury aesthetic.
