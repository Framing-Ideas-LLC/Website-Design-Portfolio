# YNA Photobooths

YNA Photobooths is a modern photography and photo booth service website designed for events, weddings, parties, and special occasions. The website uses a dark visual style with bold imagery to showcase photography services and booth experiences.

## Website Overview

The website provides visitors with information about available photo booth services, rental packages, event backdrops, pricing, and previous photography work. The layout is focused on making services easy to explore while providing multiple opportunities to book or contact the business.

## Main Sections

* Hero section with booking call-to-action
* Photo booth experience showcase
* DSLR photobooth services and pricing
* About YNA Photobooths
* Event packages and backdrop options
* Booking call-to-action section
* Pic Station and 360 Booth services
* Photography work portfolio
* Contact form
* Newsletter signup
* Footer navigation

## Design Style

The website follows a dark and modern photography-focused design. Black and dark gray backgrounds are combined with white typography and purple accent colors. Large photography images are used throughout the page to keep the services visually engaging.

## Key Features

* Responsive website layout
* Service and pricing cards
* Photo booth package showcase
* Multiple backdrop options
* Photography portfolio gallery
* Clear booking buttons
* Contact inquiry form
* Newsletter subscription
* Simple navigation structure

## Purpose

The main purpose of the website is to showcase YNA Photobooths' photography and event services, present available packages and pricing, build trust through portfolio work, and encourage visitors to book a photo booth experience for their event.
