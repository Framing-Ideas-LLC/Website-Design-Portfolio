# Medicare Monkey

A modern and approachable Medicare consultation website designed to help users understand their Medicare options and connect with a personal advisor.

## Overview

The website uses a clean, warm visual style with a strong focus on readability, trust, and simple navigation. The layout guides visitors from learning about Medicare to choosing a consultation and exploring helpful resources.

## Key Sections

* Hero section with a clear Medicare-focused message and consultation CTA
* Medicare guidance and trust-building content
* Medicare journey questionnaire
* Service cards covering Medicare-related topics
* Step-by-step Medicare process
* Personal consultation section
* Location-based Medicare guidance
* Educational articles and resources
* Consultation booking section
* Footer with navigation and contact information

## Design

* Warm off-white background with dark charcoal sections
* Green accent color for CTAs, highlights, and important information
* Large, bold typography for clear visual hierarchy
* Rounded cards and containers for a friendly appearance
* Realistic photography to create trust and a personal feel
* Responsive grid-based layout for service and resource sections

## UX Focus

The design prioritizes simple communication and easy decision-making. Users can quickly identify the Medicare services available, understand the process, explore educational content, and take the next step toward a personal consultation.

## Responsive Design

The layout is structured to adapt across desktop and mobile screen sizes while maintaining readable typography, accessible content sections, and clear calls to action.
