# FresasByKay

A modern and elegant e-commerce website designed for FresasByKay, a handmade chocolate-covered strawberry business. The website features a soft pink visual theme, product showcase sections, customer favorites, brand story, key benefits, testimonials, social media gallery, call-to-action banners, and a detailed footer.

The design focuses on creating a warm and premium experience while making it easy for customers to explore products and place orders.

### Key Features

* Responsive and user-friendly layout
* Hero section with featured products
* Customer favorites product showcase
* Brand story section
* Business benefits and features
* Customer testimonials
* Social media gallery
* Order-focused call-to-action sections
* Clean navigation and footer layout



### Design Style

The website uses a soft pink color palette combined with elegant typography and high-quality strawberry and chocolate imagery to create a sweet, premium, and handcrafted brand experience.
