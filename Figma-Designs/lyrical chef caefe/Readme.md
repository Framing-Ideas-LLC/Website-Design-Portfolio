# Lyrical Chef Cafe Website

A modern and elegant café website designed for Lyrical Chef Cafe, combining a dark luxury aesthetic with warm gold accents.

## Features

* Hero section with strong brand messaging and call-to-action buttons
* Chef introduction and brand story section
* Signature menu highlights
* Featured creations and food gallery
* Private events and catering section
* Call-to-action section for orders and directions
* Café location, contact, and opening hours
* Instagram-style image gallery
* Responsive navigation and footer
* Dark and gold visual theme throughout the website

## Design

The website uses a premium dark layout with gold typography and accents. Large serif headings, clean spacing, high-quality food photography, and structured content sections create an elegant and welcoming café experience.
