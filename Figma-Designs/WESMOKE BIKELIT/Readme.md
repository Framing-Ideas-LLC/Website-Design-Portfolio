# Wesmoke Bikelit

A modern motorcycle-inspired streetwear website designed for riders who want a bold and distinctive style.

## Features

* Bold and modern hero section
* Motorcycle and streetwear focused visual design
* Product showcase and latest drop section
* Category-based product collections
* Featured product promotions
* Custom denim and motorcycle gear sections
* Lifestyle-focused content sections
* Color collection showcase
* Responsive product grid layout
* Strong call-to-action sections
* Dark navy, red, yellow, blue, and neutral color palette
* Bold condensed typography for a strong streetwear aesthetic

## Sections

* Hero
* Featured Categories
* Latest Drop
* Featured Collection
* Brand Story

## Design Style

The design combines motorcycle culture with modern streetwear aesthetics, using bold typography, high-contrast colors, editorial layouts, and strong photography to create a premium and energetic visual experience.
