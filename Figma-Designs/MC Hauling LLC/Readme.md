# MC Hauling LLC Website

## Project Overview
A modern, responsive website for MC Hauling LLC, a junk removal and hauling service. The website focuses on helping customers easily book services, request quotes, and understand pricing.

## Key Features
- Responsive homepage design for desktop and mobile devices.
- Hero section with a clear headline and call-to-action buttons.
- About section introducing the company and its hauling services.
- Services section showcasing junk removal, cleanouts, and hauling solutions.
- Benefits section highlighting convenient and hassle-free service.
- Service information for garage cleanouts, heavy lifting, and unwanted item removal.
- Request a Quote form for collecting customer details and job requirements.
- Booking section for scheduling a service.
- Transparent pricing section with a simple payment process.
- Customer testimonials section.
- Final call-to-action section encouraging customers to book a service.
- Footer with company information and navigation links.

## Design Highlights
- Modern black, white, and red color scheme.
- Bold typography and clear content hierarchy.
- High-quality service images.
- Clean layouts with consistent spacing.
- Strong call-to-action buttons throughout the website.
- Mobile-friendly layout for a better user experience.
