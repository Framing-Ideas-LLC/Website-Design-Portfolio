# Care & Support Website

A modern and responsive healthcare and care support website designed to present care services, build trust, and make it easy for users to get in touch.

## Features

* Modern healthcare-focused landing page
* Responsive design for desktop, tablet, and mobile
* Hero section with clear call-to-action
* Care and support service sections
* Service cards with supporting images
* Trust and credibility sections
* Testimonials section
* Care team profiles
* Step-by-step care process
* FAQ section
* Contact and inquiry form
* Strong CTA sections throughout the website
* Clean and accessible layout
* Footer with navigation and contact information

## Sections

* Hero
* About / Care Support
* Services
* Trust & Care Information
* Getting Started
* Care Moments
* Care Team
* Testimonials
* FAQs
* Contact
* Footer

## Design

The website uses a clean, professional healthcare aesthetic with soft backgrounds, strong typography, photography, and a clear visual hierarchy. The layout focuses on trust, accessibility, readability, and conversion.

## Purpose

The website is designed to help users understand available care services, learn about the care team, build confidence through testimonials and trust elements, and easily request more information or start a care conversation.
