## Walls of Bloomscape – Silk Flower Wall Rental Website (Figma UI/UX)

**Walls of Bloomscape** is a modern event décor website concept designed in **Figma** to showcase beautiful, high-quality silk flower walls for weddings, celebrations, parties, and special events across Northeast Florida. As a locally owned business built around a passion for creating memorable floral experiences, the design focuses on bringing elegance, creativity, and visual impact to every event.

The website is crafted to highlight flower wall collections, event décor options, rental packages, gallery inspiration, event types, and booking services while delivering a seamless experience across all devices. Elegant floral visuals, sophisticated layouts, soft typography, and intuitive navigation create an engaging journey for customers planning beautiful and memorable occasions.
