# WeBike Global

A modern cycling community website designed to promote cycling, community engagement, and an active lifestyle.

## Features

* Full-screen hero section with strong cycling-focused messaging
* Community statistics and membership highlights
* Upcoming cycling event section
* Membership benefits section
* Cycling experience and photo gallery
* Community testimonial section
* Instagram feed integration
* Strong call-to-action sections
* Responsive footer with navigation and newsletter signup

## Design

The website uses a dark, premium visual style with cycling photography, bold typography, green accent colors, and structured content sections to create an energetic community-focused experience.
