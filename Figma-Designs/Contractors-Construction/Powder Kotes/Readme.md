# Whitsundays Fabrication Website

A modern, responsive website designed for a professional aluminium, stainless steel, and glass fabrication company based in Queensland.

## Overview

The website presents Whitsundays Fabrication’s services, completed projects, experience, and capabilities through a clean and professional layout. The design focuses on building trust with architects, builders, and homeowners while making the company’s fabrication services easy to explore.

## Key Features

* Professional hero section with clear calls to action
* Company experience and trust indicators
* Service showcase for architectural fabrication
* Project portfolio with visual project galleries
* Client testimonials
* Location and service area section
* Strong call-to-action sections
* Responsive layout for desktop and mobile
* Clean navigation and structured footer

## Services Highlighted

* Glass Balustrades
* Powder Coated Aluminium
* Stainless Steel Handrails
* Glass Pool Fencing
* Privacy Screens
* Electric Gates

## Design Approach

The website uses a modern architectural aesthetic with strong typography, high-quality project imagery, dark navy sections, and clean white layouts. The overall design is focused on professionalism, readability, and showcasing completed fabrication work.

* HTML
* CSS
* JavaScript
