# Hard Knox Epoxy

A modern, responsive website design for Hard Knox Epoxy, a premium epoxy flooring company serving residential and commercial spaces.

## Features

* Premium hero section with strong calls to action
* Company story and brand introduction
* Services and flooring solutions showcase
* Benefits and key selling points section
* Customer testimonials
* Lead generation call-to-action section
* Clean and structured footer navigation
* Responsive layout designed for modern devices

## Design

The website uses a clean industrial aesthetic with a dark and white color combination, supported by vibrant orange accents. Large imagery, bold typography, rounded cards, and clear content sections create a premium and professional look.


## Technologies

* HTML
* CSS
* JavaScript

## Purpose

The website is designed to build trust, showcase epoxy flooring expertise, highlight services, and encourage visitors to request a free estimate.
