# CLJ Interiors

A modern and premium interior design website for CLJ Interiors, focused on residential renovation, interior transformation, and personalized design services.

## Features

* Premium interior design focused homepage
* Full-width hero section with clear call-to-action
* Interior renovation and transformation showcase
* Project portfolio with visual cards
* Company introduction and team section
* Before-and-after transformation section
* Step-by-step project process
* Services and project highlights
* Reasons to choose CLJ Interiors
* Project enquiry form
* Client testimonials
* Strong final call-to-action section
* Responsive layout for different screen sizes
* Clean typography with a modern luxury aesthetic
* Gold, white, and dark color palette
* Image-focused sections for showcasing completed interiors

## Sections

* Hero
* Introduction
* Project Showcase
* About / Team
* Transformations
* Project Process
* Featured Work
* Why Choose CLJ
* Project Enquiry
* Client Testimonials
* Final CTA
* Footer

## Design Style

The website uses a premium interior-design aesthetic with large photography, dark sections, warm gold accents, clean layouts, rounded cards, and strong visual hierarchy.

## Purpose

The main goal of the website is to showcase CLJ Interiors' work, build trust through projects and testimonials, explain the renovation process, and encourage visitors to submit a project enquiry.
