# Basele Studio

A sophisticated beauty studio website designed with a dark, elegant aesthetic and a strong focus on visual presentation.

## Features

* Elegant hero section with beauty-focused imagery
* Introduction and brand story section
* Signature services showcase
* Portfolio and work gallery
* Step-by-step experience section
* Client testimonials
* Service pricing section
* Appointment booking call-to-action
* Clean footer with navigation and contact information

## Design

The website uses a deep burgundy color palette with warm typography and editorial-style imagery to create a luxurious and feminine visual experience. The layout combines large photography, refined typography, spacious sections, and subtle accent colors for a premium beauty studio feel.
