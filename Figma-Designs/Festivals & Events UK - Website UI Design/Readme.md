# Festivals & Events Website

A modern, dark-themed festival and events discovery platform designed to help users explore upcoming festivals, discover live events, and find their next weekend experience.

## Project Overview

The website features a premium visual design with a dark background, vibrant event photography, purple gradients, and bright lime-green accents. The layout focuses on easy navigation, event discovery, and an engaging browsing experience.

## Main Sections

### 1. Hero Section
- Full-width festival background image.
- Bold headline with highlighted text.
- Short introductory description.
- Explore Events and Submit Your Event buttons.
- Navigation menu with a highlighted CTA.

### 2. Upcoming Events

### 3. Featured Festivals
