# High Profile Decor

A modern luxury interior design website created for High Profile Decor, showcasing high-end residential and commercial decorating services with an elegant and sophisticated visual style.

## Features

* Luxury interior design and decorating services
* Residential and commercial decorating
* Color consultation
* Home staging
* Room makeovers
* Vacation rental styling
* Interior design story and brand introduction
* Exclusive home decor product collection
* Product pricing and collection showcase
* Consultation booking form
* Contact and assessment section
* Responsive and modern layout

## Design

The website uses a dark luxury aesthetic with gold accents, elegant typography, large interior photography, and spacious layouts to create a premium feel. The overall design focuses on sophistication, exclusivity, and high-end interior design.
