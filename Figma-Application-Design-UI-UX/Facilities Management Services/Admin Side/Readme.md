### Admin Side – App UI/UX Design

The **FMS Admin Side** is a management interface designed to give administrators centralized control over customers, employees, service requests, maintenance tasks, facilities, and overall operations.

The dashboard provides a structured overview of activities, allowing admins to monitor requests, assign tasks, manage users, track progress, and maintain smooth day-to-day facility operations.
