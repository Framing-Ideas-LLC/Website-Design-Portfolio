# OASIS Roadside Assistance - App UI/UX

### Roadside Assistance Mobile App

**OASIS Roadside Assistance** is a mobile application concept designed to provide drivers with quick, convenient, and reliable roadside support when they need help on the road. From unexpected breakdowns and flat tires to towing and other roadside emergencies, the app is designed to connect users with the assistance they need through a simple digital experience.

## Project Overview

The OASIS app was designed with a **speed-first and user-focused approach**, recognizing that users typically need roadside assistance when they are already in a stressful or inconvenient situation.

The interface focuses on simplicity, clear service options, location-based assistance, and straightforward actions. A clean visual hierarchy and intuitive navigation help users quickly understand their options and request the appropriate roadside service.



## Design Goals

* Create a simple and reliable roadside assistance experience
* Help users request assistance quickly
* Make emergency service options easy to understand
* Reduce friction during stressful roadside situations
* Provide clear service selection and request flows
* Make location and assistance details easy to access
* Build trust through a professional and approachable interface
* Create a responsive and user-friendly mobile experience

## Key Features

### Welcome Experience

A simple onboarding and welcome experience introduces users to OASIS and communicates the app's core purpose from the beginning.

### Roadside Assistance Services

Users can explore and select different roadside assistance options based on their specific situation.

### Service Request Flow

A straightforward request process helps users provide the necessary information and request assistance without unnecessary steps.

### Location-Based Assistance

The experience is designed around location information so users can communicate where assistance is required.

### Emergency Support

Important actions and assistance options are presented prominently to help users access support when they need it most.

### Request Status

The app experience provides users with relevant information about their assistance request, helping them stay informed throughout the process.

### User-Friendly Navigation

Clear navigation and organized content allow users to move between services, requests, account information, and other important areas with minimal effort.

### Customer & Service Information

Relevant details are presented in a structured format so users can easily review their selected service and request information.

## Visual Direction

The visual direction focuses on **reliability, safety, accessibility, and responsiveness**. The interface uses a clean layout, strong visual hierarchy, recognizable icons, and prominent action areas to ensure important information can be understood quickly.

The design avoids unnecessary complexity and keeps the primary actions easily accessible, creating an experience that feels dependable during both everyday vehicle issues and urgent roadside situations.

## UX Approach

The OASIS experience follows a straightforward user journey:

**Open App → Select Service → Share Location → Request Assistance → Track Request → Get Support**

Each step is designed to minimize user effort and provide clear feedback, allowing users to focus on getting help rather than navigating a complicated application.
