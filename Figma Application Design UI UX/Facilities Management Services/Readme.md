# Facilities Management Services (FMS)

### Mobile App UI/UX Design

**Facilities Management Services (FMS)** is a mobile application concept designed to simplify the management of facilities, maintenance operations, service requests, and day-to-day property-related tasks through one centralized digital experience.

The app brings essential facility management activities into a structured and easy-to-use interface, helping users monitor requests, manage maintenance tasks, track work progress, and access important facility information more efficiently.

## Project Overview

The FMS app was designed with a focus on **organization, operational efficiency, and accessibility**. The experience helps users manage multiple facility-related activities without relying on disconnected communication channels or manual processes.

A clean dashboard, structured navigation, clear status indicators, and task-focused workflows make it easier for users to understand what requires attention and take action quickly.



## Design Goals

* Create a centralized facility management experience
* Simplify maintenance and service request management
* Make tasks and work orders easy to track
* Provide quick access to important facility information
* Improve visibility into ongoing and completed requests
* Reduce complexity in day-to-day facility operations
* Create an organized and scalable mobile interface
* Support efficient communication between users and service teams

## Key Features

### Dashboard

A centralized dashboard provides an overview of important facility activities, pending requests, ongoing tasks, completed work, and other relevant information.

### Service Requests

Users can create and submit facility-related service or maintenance requests through a simple and structured process.

### Maintenance Management

Maintenance tasks can be organized and monitored, allowing users to understand what needs attention and the current progress of each task.

### Work Order Tracking

A dedicated workflow helps users monitor work orders from creation through completion, providing better visibility into operational activities.

### Task Status

Clear status indicators help users quickly understand whether a request is pending, in progress, completed, or requires further attention.

### Facility Information

Important information related to facilities, locations, assets, and services can be organized within the application for quick access.

### Notifications

Relevant updates and notifications keep users informed about service requests, maintenance activities, task progress, and important changes.

### User & Account Management

Users can manage their profile, preferences, and relevant account information through an organized account experience.

## Visual Direction

The visual direction focuses on **clarity, organization, efficiency, and professionalism**. The interface uses structured layouts, clear typography, recognizable icons, status indicators, and organized information blocks to make operational data easier to understand.

The design balances functionality with a clean visual system, allowing users to navigate multiple facility management functions without feeling overwhelmed.

## UX Approach

The FMS experience follows a task-oriented user journey:

**Dashboard → Identify Task → Create / Review Request → Assign or Track Work → Monitor Progress → Complete**

The workflow is designed to reduce unnecessary steps while keeping important information visible at each stage of the process.
