### Customer Side – App UI/UX Design

The **FMS Customer Side** is a mobile app experience designed to help customers easily submit service requests, report maintenance issues, track request progress, and stay updated throughout the service process.

The interface focuses on simplicity and transparency, allowing customers to quickly communicate their needs and monitor the status of their requests from one centralized platform.

### Project Highlights

* Customer Dashboard
* Service Request Submission
* Maintenance Issue Reporting
* Request Status Tracking
* Service History
* Request Details
* Notifications & Updates
* Appointment / Schedule Information
* Facility & Service Information
* Customer Profile
* Simple Navigation
* Mobile-First UX
* High-Fidelity Figma UI
* Interactive Prototype
* Reusable UI Components
* Consistent Design System

**Core Values:** Convenience • Transparency • Responsiveness • Accessibility • Customer Service

**Tools:** Figma • UI/UX Design • Auto Layout • Design System • Interactive Prototype • Mobile App Design
