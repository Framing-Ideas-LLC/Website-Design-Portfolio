### Employee Side – App UI/UX Design

The **FMS Employee Side** is a mobile app experience designed to help facility staff manage assigned tasks, service requests, maintenance activities, and work updates efficiently.

The interface provides employees with a clear view of their responsibilities, task statuses, schedules, and important updates, helping them stay organized and complete daily facility operations smoothly.

### Project Highlights

* Employee Dashboard
* Assigned Tasks & Work Orders
* Maintenance Requests
* Task Status Tracking
* Service Request Updates
* Work Schedule & Activities
* Notifications
* Task Details & Instructions
* Facility & Location Information
* Simple Navigation
* Mobile-First UX
* High-Fidelity Figma UI
* Interactive Prototype
* Reusable UI Components
* Consistent Design System

**Core Values:** Efficiency • Organization • Responsiveness • Productivity • Clear Communication

**Tools:** Figma • UI/UX Design • Auto Layout • Design System • Interactive Prototype • Mobile App Design
